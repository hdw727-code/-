학생 조사 링크 만들기

선생님 폼에 연결된 내 반 전용 학생 링크를 만듭니다 · 약 3분

1조사 폼 준비하기

이미 폼이 있으면 2번으로 건너뛰세요.
  1. 받으신 사본 만들기 링크를 열고 [사본 만들기]를 누릅니다.
  2. 문항 8개가 그대로 들어간 폼이 내 드라이브에 생깁니다.
  3. 응답은 선생님에게만 쌓입니다.
문항 제목의 낱말(번호·이름·유형·1지망·학과·2지망·이유·선생님께)은 바꾸지 마세요. 상황판이 이 낱말로 열을 찾습니다.

2미리 채워진 링크 가져오기

폼의 문항 번호를 알아내기 위해 필요합니다. 학생에게 보내는 링크가 아닙니다.
  1. 폼 편집 화면 오른쪽 위 ⋮ → [미리 채워진 링크 가져오기]
  2. 열린 화면에서 모든 칸에 아무 글자나 넣습니다. (예: 1, 2, 3 … / 객관식은 아무거나 선택)
  3. 맨 아래 [링크 가져오기] → [링크 복사]
  4. 복사한 주소를 아래에 붙여 넣으세요.

3문항 짝 맞추기

순서대로 자동으로 맞춰 두었습니다. 내가 넣은 값을 보고 다르면 고쳐 주세요.

4우리 반 정보

비평준화(시흥·화성·평택 등)는 학교 한 곳에 직접 지원, 평준화(안산·수원·안양권 등)는 지망 순위를 적어 배정받습니다. 학생에게 나가는 안내가 정반대라 꼭 맞게 고르세요.

5완성 — 학생에게 보낼 링크

학생에게 보내기 전에 선생님이 먼저 한 번 제출해 보세요. 미리 보기로 들어가 끝까지 제출한 뒤, 폼 [응답] 탭에 칸이 제대로 들어갔는지 확인하세요. 칸이 밀려 있으면 3번으로 돌아가 짝을 고치면 됩니다. (확인용 응답은 지우시면 됩니다.)
응답이 모이면 폼 [응답] 탭 → ⋮ → [응답 다운로드(.csv)] → 진학 상황판에 올리면 학생별 상담 카드가 만들어집니다.
이 페이지는 선생님 컴퓨터 안에서만 동작하며, 입력한 내용을 어디로도 보내지 않습니다. 만들어진 링크에는 폼 주소와 문항 번호만 들어 있고 학생 정보는 들어 있지 않습니다.
