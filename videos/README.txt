① 관찰 화면에 띄워 줍니다. 아이들은 영상을 보고 → 본 것을 프롬프트로

■ 준비물
  · 이 videos 폴더는 반드시 프롬프트챔피언.html 과 같은 폴더에 두세요.
      내 폴더/
        프롬프트챔피언.html
        videos/          ← 이 폴더
          run.mp4
          jump.mp4
  · 캡컷에서 "내보내기" → 720p / mp4 로 저장하면 됩니다.
    (mp4 · webm · mov · m4v 모두 됩니다.)
  · 길이는 4~10초가 가장 좋습니다. 동작 한 번만 딱 보이게 잘라 주세요.
  · 소리는 있어도 되고 없어도 됩니다.

      공용 이름보다 먼저 쓰입니다.

■ 자주 묻는 것
  · 영상을 안 넣어도 게임은 그대로 잘 돌아갑니다. ① 관찰을 누르면
    "이 이름으로 넣어주세요" 안내가 나옵니다.
  · 영상이 안 보이면 → 파일 이름의 대소문자와 확장자를 확인하세요.
    한글 파일명은 쓰지 마세요.
  · 수업 중에 급하면 ① 관찰 화면 아래 "파일 직접 고르기"로 그때그때
    영상을 열 수도 있습니다. (그 수업만 임시로 적용됩니다.)
  · 영상 속 단계(①②③④)는 게임이 자동으로 나눕니다. 영상을 동작
    시작~끝만 남기고 자르면 단계가 훨씬 정확하게 맞습니다.

■ 영상이 아직 없어도 — 게임 안에 시범 장치가 있습니다 (새로 추가)
  · 📐 코칭선 : 무릎·팔꿈치 같은 관절에 점과 각도를 띄워, 어디를 봐야
    하는지 짚어 줍니다. (재생바에서 켜고 끄기)
  · 🎬 시범   : 멀리서 달려오는 연출을 끄고, 제자리에서 크기 그대로
    옆모습으로 보여 줍니다. 보폭과 팔치기를 보기에 좋습니다.
  · 🆚 비교   : 미션을 깬 뒤 "애매하게 말했다면?"을 누르면, 같은 코치봇이
    애매한 프롬프트와 구체적인 프롬프트에서 각각 어떻게 움직이는지
    좌우로 나란히 보여 줍니다.
