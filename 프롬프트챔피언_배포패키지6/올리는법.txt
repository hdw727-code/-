■ 준비물: 이 압축을 푼 폴더
    prompt-champion.html   ← 게임 본체 (이름 바꾸지 마세요!)
    videos/README.txt      ← 영상 파일 이름표 + 유튜브 등록법
    videos/links.txt       ← 유튜브 링크 등록 파일 (📺 새 기능!)

■ 올리기 (PC 브라우저에서)
  1. github.com/hdw727-code/-  접속 후 로그인
  2. [Add file] → [Upload files] 클릭
  3. 압축 푼 폴더 안의 "내용물"을 전부 드래그해서 놓기
     (prompt-champion.html 과 videos 폴더째로 — 폴더 드래그 됩니다)
  4. 아래 초록색 [Commit changes] 클릭
  5. 1~2분 기다렸다가 접속:
     https://hdw727-code.github.io/-/prompt-champion.html
     예전 화면이 보이면 Ctrl+F5 (강력 새로고침)

■ 📺 유튜브 영상 등록 (다운로드 불필요 — 새 기능!)
  1. 유튜브에서 좋은 시범 영상을 찾고, 쓸 구간의 시작·끝 시간 확인
  2. GitHub 저장소에서 videos → links.txt 클릭 → 연필(✏️)로 수정
  3. 한 줄 추가:   m03: https://youtu.be/영상주소 1:05 1:12
     (미션 번호표는 videos/README.txt 에 있습니다)
  4. [Commit changes] → 그 미션의 ① 관찰 화면에서 해당 구간만
     반복 재생됩니다. 슬로우·단계 점프도 됩니다!
  ※ 공식 유튜브 임베드 방식이라 저작권 걱정이 없습니다.
  ※ ③ 비교(캐릭터와 나란히)는 파일 방식 영상에서만 됩니다.

■ 직접 찍은 영상(캡컷)은 이렇게 추가
  1. 캡컷에서 mp4(720p)로 내보내기
  2. 파일 이름을 videos/README.txt 의 이름표대로 변경 (예: run.mp4)
  3. GitHub 저장소에서 videos 폴더 → [Add file] → [Upload files]
     → 영상 드래그 → [Commit changes]

■ 참고
  · 영상·링크가 없어도 게임은 완전하게 돌아갑니다 (코칭선·시범·비교 내장)
  · 학생 접속 주소는 위 주소 하나면 됩니다 (설치 불필요, 폰·태블릿 OK)
  · 진행 저장은 "이어하기 코드"로 됩니다 — 서버가 없어도 괜찮아요
